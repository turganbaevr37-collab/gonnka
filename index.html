About this first version

Designed for a teacher-operated classroom workflow. QR codes contain opaque IDs only. The scanner includes automatic paper-background removal and manual brush correction; marker-based perspective correction is a best-effort enhancement, with photo upload and manual crop as fallback. Vehicle display is an honest 2.5D presentation of the student’s original drawing, not a fully reconstructed 3D object.

Camera access requires HTTPS or localhost. External libraries load from public CDNs, so the first page load requires an internet connection.
